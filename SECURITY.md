# Security Policy

## Supported Versions

Security updates and patches are provided for the following versions:

| Version | Supported |
|---|---|
| 3.2.x | Yes |
| < 3.2 | No |

## Reporting a Vulnerability

We take the security and integrity of Switchyard seriously. If you discover a security vulnerability or potential compliance flaw, please report it responsibly.

### Disclosure Process

Please submit security vulnerability reports privately via GitHub Security Advisories at:
https://github.com/NatthaphongY/switchyard-logistics/security/advisories/new

Alternatively, reach out directly to the maintainer via the contact profile listed on GitHub:
https://github.com/NatthaphongY

Please do not open public GitHub issues or discussions for undisclosed security vulnerabilities.

### What to Include

When reporting a vulnerability, please provide:
1. A detailed description of the issue and its potential impact.
2. Step-by-step instructions or proof-of-concept code to reproduce the issue.
3. Affected versions, environment details, and relevant platform configurations.

### Response Timeline

- Acknowledgement: Within 48 hours of receipt.
- Assessment: Initial validation and triage within 5 business days.
- Remediation: Coordinated patch release following verification and testing.
